## 截图建议

- 使用 PNG 格式。
- 建议截图前压缩（例如 macOS `sips -Z 1600` 缩至最长边 1600px），保持仓库体积精简。
- 截图前请先启动后端和前端（见 README「快速开始」），并使用演示账号登录：

  | 角色 | 用户名 | 密码 |

  | 教师 | `T2024001` | `123456` |

- 建议在无敏感数据的环境下截图，避免暴露真实个人信息。
